SOCIAL MEDIA DESIGN COLLECTION 2026 — HTML SOURCE
Asiri Gayashan

FILES
  index.html  - the full portfolio page (1400px wide)
  cover.html  - the Behance cover thumbnail (808 x 632)
  images/     - your 24 posts (file names are used inside the HTML)
  fonts/      - Anton, Archivo, JetBrains Mono, Instrument Serif

HOW TO VIEW
  Keep all files in this folder together and open index.html in Google Chrome.

HOW TO EDIT
  Open index.html in any text editor (VS Code is free and easy).
  - Text: search for the words you want to change and type over them.
  - Your email / Behance link: search for "your@email.com" and "behance.net/yourname".
  - Colours: search for the hex codes, e.g. #FF4D1A (orange), #1E9E3E (Luyuan green),
    #E31E24 (Kiaway red), #FFF200 (Sakura yellow), #8E1B2C (Rising Sri Lanka maroon),
    #22C55E (Shane green).
  - Brand chapters: the text for every chapter is in the list that starts with "const CH=["
    near the bottom of the file.
  - Swap a post: replace a file in images/ with a new image using the same file name.

HOW TO EXPORT IMAGES FOR BEHANCE
  1. Open index.html in Chrome and press F12 (Developer Tools).
  2. Press Ctrl+Shift+M and set the width to 1400.
  3. Press Ctrl+Shift+P, type "screenshot" and choose:
     - "Capture full size screenshot" for the whole page, or
     - select a <section> in the Elements panel first, then "Capture node screenshot"
       to export one section at a time (this is how the Behance images were made).
  Do the same with cover.html for the thumbnail.
